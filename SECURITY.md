# Reporting a security issue

Email hello@codebakery.net with the subject `DeviceYard security report`.
Do not disclose vulnerabilities in public issues or pull requests before
coordinating with the maintainer.

Include the affected revision/version and edition, deployment method, impact,
and minimal reproduction steps. Remove credentials, personal data, APKs and
private test artifacts from logs and screenshots. If sensitive evidence is
needed, first ask for a suitable transfer method rather than attaching it.

Reports are reviewed by the maintainer; this project does not promise a fixed
response SLA. Use an isolated installation for testing and do not probe farms
or devices you do not own or have permission to test.
